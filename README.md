# 📊 Social Media Analytics Dashboard – Final Insights

This project analyzes engagement, user behavior, and sentiment trends across social media platforms.  
The insights below summarize **content performance, user trends, behavioral patterns, and sentiment analysis**.

---

## 📌 Content Performance
- **Highest Engagement Post Types**: Short‑form videos & carousel posts outperform static images.
- **Best‑Performing Category**: Entertainment & lifestyle content lead, followed by educational "how‑to" posts.
- **Top Countries by Engagement Rate**:  
  | Country | Avg. Engagement Rate |
  |---------|----------------------|
  | India   | Highest watch‑time   |
  | U.S.    | Strong interaction   |
  | Brazil  | High engagement      |

---

## 👥 User Trends
- **Age vs. Engagement**  
  - 18–24: High frequency, shorter attention span  
  - 35+: Lower frequency, longer watch‑time  
- **Verified Accounts**: ~25–30% higher engagement due to credibility & algorithmic preference.

---

## ⏱️ Behavioral Insights
- **Best Time for Impressions**: 6–9 PM local time (post‑work leisure browsing).  
- **Device Impact on Watch Time**:  
  | Device   | Behavior |
  |----------|----------|
  | Mobile   | 70%+ of watch‑time, quick interactions |
  | Desktop  | Longer sessions, especially for educational/professional content |

---

## 💬 Sentiment Analysis
- **Best‑Performing Sentiment**: Positive (motivational, humorous, celebratory).  
- **Negative/Neutral Behavior**:  
  - Negative → High comments, low shares  
  - Neutral → Steady performance, rarely viral

---

## ✅ Key Takeaways
- Prioritize **video & carousel formats** for reach.  
- Tailor content by **age group** (snackable vs. in‑depth).  
- Use **positive sentiment storytelling** to maximize shares.  
- Optimize posting around **evening hours**.  
- Ensure **mobile‑first design**.  
- Verified status significantly boosts visibility.

---

## 📂 Project Structure
- **Dashboard**: Power BI / Excel visualizations  
- **Data**: Engagement metrics, sentiment classification, device usage  
- **Documentation**: README insights + recruiter‑friendly tables
